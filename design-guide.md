# Guia de Design - Clínica Aplicar

Este documento estabelece as diretrizes visuais para o projeto da Clínica Aplicar, garantindo consistência em toda a interface.

## 🎨 Paleta de Cores

| Tipo | Hexadecimal | Descrição |
| :--- | :--- | :--- |
| **Primária** | `#FFFFFF` | Cor de fundo predominante (Background). |
| **Secundária** | `#496897` | Cor utilizada em textos, botões e elementos de destaque. |

## 🖋️ Tipografia

A tipografia escolhida para este projeto é a **Poppins**.

*   **Tipografia Principal:** `Poppins-Semibold`
    *   **Uso:** Títulos de nível 1 (**H1**).
*   **Tipografia Secundária:** `Poppins-Regular`
    *   **Uso:** Textos corridos, parágrafos e títulos de nível 2 (**H2**).

## 🔳 Componentes e Layout

### Fundo (Background)
- Toda a interface deve utilizar a **Cor Primária (`#FFFFFF`)** como base de fundo.

### Textos e Títulos
- **H1:** `Poppins-Semibold` | Cor: `#496897`
- **H2 / Parágrafos:** `Poppins-Regular` | Cor: `#496897`

### Botões
- **Cor de Fundo:** `#496897` (Secundária)
- **Texto do Botão:** `#FFFFFF` (Primária)
- **Tipografia:** `Poppins-Regular`
